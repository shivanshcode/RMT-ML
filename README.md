## To run rmt analysis on supercollapse's MLP with and without muP
1. conda activate shreesupercollapse
2. run rmt mlp sweep slurm
3. get the checkpoints in the ./ckpts folder. 

Then go to rmt-repo
1. run the rmt sweep.
