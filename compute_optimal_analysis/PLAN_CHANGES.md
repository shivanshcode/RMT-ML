# Record of contract reconciliation

This record explains the reconciliation of the legacy RMT plan and the Spectral-Chinchilla request.

1. The supplied plan specifies an offline analyzer for Hugging Face checkpoints. Spectral-Chinchilla trains a decoder-only Transformer family with `models/` and `pipelines/`. The project keeps applicable pure-science signatures. Phase II ports applicable WeightWatcher formulas without its notebook or runtime stack. Phase III adds local asset staging and an offline SLURM launcher.
2. The current import limit is stricter than the supplied optional GPU SVD design. `rmt.linalg.cached_svd` uses only NumPy. `pipelines.spectral_lesioning` contains the torch SVD operations.
3. `SVDResult` gives raw Gram eigenvalues as `s^2`. It gives normalized covariance eigenvalues separately. This difference agrees with the requested dataclass and the MP covariance law.
4. Centered activation covariance is the default. Use `second_moments()` or `centered=False` for the requested uncentered `X^T X/n` quantity.
5. The tranche names are top, bulk, and bottom. Singular values stay in descending order. The three-tranche benchmark does not use numeric deciles. The separate `reference_decile` path reproduces codebase1, where decile zero contains the largest values.
6. The regime multiplier changes a fixed-compute surface. The formulas are `D=kappa D*` and `N=N*/kappa`. They preserve `C=6ND` and the intended model-size comparison.
7. Heavy-tailed spectra, bottom-lesion perplexity order, and scaling collapse are empirical hypotheses. Unit tests contain synthetic calibrations. Only experiment output can support claims about trained models.
8. The project did not copy the numerical execution status from the supplied project. `bug_report.md` records local tests and the status of each finding. CUDA and HPC experiments stay as operator gates.
9. Phase II corrects two short statements in the request. FARMS pools fixed-ratio submatrices and is not a pointwise map. Under identity noise, the BBP population threshold is `1+sqrt(q)`, not `1+q`.
10. Lanczos boundary estimation uses the Cholesky-coefficient constant-tail construction from the supplied paper. It reports assumptions and convergence diagnostics. It does not claim exact results for arbitrary neural spectra.
